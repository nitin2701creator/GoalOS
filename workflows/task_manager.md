# GoalOS Task Manager

## Purpose

The Task Manager receives work from the Goal Engine and distributes it to the correct agents.

---

## Responsibilities

- Accept tasks from Goal Engine
- Determine required skills
- Select appropriate agent
- Assign priority
- Set deadlines
- Track completion
- Reassign failed tasks
- Escalate blocked tasks

---

## Priority Levels

### Critical
Business stopping issues

### High
Revenue impacting work

### Medium
Growth work

### Low
Background improvements
