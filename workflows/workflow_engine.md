# GoalOS Workflow Engine

## Purpose

The Workflow Engine coordinates multi-step business processes across multiple agents.

---

## Responsibilities

- Build workflows
- Execute workflows
- Monitor progress
- Handle dependencies
- Retry failed steps
- Roll back if necessary
- Notify stakeholders
