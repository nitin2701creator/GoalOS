# Autonomous Development System Roadmap

## Purpose

The Autonomous Development System (ADS) will provide a controlled workflow for turning approved development work into verified repository changes.

## Milestones

1. Define ADS domain models and file-backed planning artifacts.
2. Add backlog, roadmap, and scheduling interfaces.
3. Add planning, prompting, worker, verification, and review boundaries.
4. Add orchestration, Git safety, and memory integration points.
5. Integrate ADS through an application service after the module contracts are stable.

## Guardrails

- Preserve human approval points for consequential actions.
- Keep execution, verification, and review responsibilities separate.
- Record decisions and session context in the files in this directory.
