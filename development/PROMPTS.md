# Autonomous Development System Prompts

## Prompt Principles

- State the task objective, constraints, and acceptance criteria.
- Include only the repository context needed for the assigned work.
- Require a summary of proposed changes and verification evidence.
- Preserve explicit human approval requirements.

## Starter Template

```text
Objective: {objective}
Constraints: {constraints}
Acceptance criteria: {acceptance_criteria}
Repository context: {repository_context}
```

Prompt construction is intentionally not implemented in this foundation.
